QR CODE — IMPORTANT
====================
A QR code can open this birthday website on Jessy's phone only when the website has a public HTTPS address.

This ZIP already contains all 15 image files and the complete birthday website.

Recommended free hosting options:
- GitHub Pages: create a repository, upload the contents of this folder, enable Pages, then copy the HTTPS URL.
- Netlify Drop: drag this folder onto Netlify's deploy page and copy the HTTPS URL.

Once you have the public URL, generate a QR code for that URL. You can print it on a birthday card.

Do NOT make the QR point to file:///... or a Windows C: drive path; those will not work on her phone.
